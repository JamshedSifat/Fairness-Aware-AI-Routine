## 🌟 About the Project

**Fairness-Aware AI Routine Generator** is a research project exploring how Artificial Intelligence can help create university academic routines that are:

- ⚖️ Fair
- 👨‍🎓 Student-friendly
- 👨‍🏫 Teacher-aware
- 📚 Academically balanced
- 🏫 Resource-aware
- ⏰ Time-efficient
- 🤖 AI-driven

Traditional routine generation mainly focuses on satisfying scheduling constraints.

This project explores an additional question:

> **How can an AI system generate a routine that is not only feasible, but also fair to the people affected by it?**
